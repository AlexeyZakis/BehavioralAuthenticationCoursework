# Дипломный LaTeX-проект

Тема: «Сравнение моделей машинного обучения для поведенческой аутентификации в библиотеке Android-приложения».

Проект переработан вокруг постановки из презентации: проблемы традиционной аутентификации, проблемы существующих сравнений моделей, архитектура Android-библиотеки, сбор сырых событий, временные окна, детекторы аномальности, детекторы смены пользователя и метрики сравнения точности/нагрузки.

## Сборка

```bash
make
```

Библиография оформлена непосредственно в `thesis.tex` через `thebibliography`, поэтому BibTeX не требуется. Файл `references.bib` оставлен в архиве как дополнительный список источников и для совместимости с шаблоном примера.

## Основные файлы

- `thesis.tex` — основной текст диплома.
- `thesis.pdf` — скомпилированная версия.
- `BYUPhys.cls` — класс шаблона из примера.
- `gzlogo.png` — логотип для титульного листа.
- `Makefile` — сценарий сборки.
